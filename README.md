An online pomodoro for the MMO WoW: Forever.

## Introduction

A session of WoW: Forever has no natural stopping point, so it is easy
to look up and find the evening gone.
WoModoro runs in the browser and breaks play into timed focus blocks
with breaks between them, so you decide when to stop before you sit
down rather than after.
